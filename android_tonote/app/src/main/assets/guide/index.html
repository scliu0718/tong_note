同笔记怎么用

笔记写在你自己的百度网盘里。先记在手机上，联网后自动同步，和 Mac / Windows 端互通。

登录 笔记 写笔记 表格 快任务 同步 我的 常见问题

登录

点「使用百度网盘账号登录」，在授权页登录百度账号并同意授权，完成后会自动回到同笔记。

  • 同笔记只读写你网盘里的 /apps/tong_log 目录，不会碰你网盘里的其他文件。
  • 授权信息只保存在这台手机上，没有任何中间服务器。
  • 在「我的」页能看到当前登录的百度账号。

笔记

底部「笔记」是首页：顶部是笔记本（绿色）和标签（蓝色），下面是搜索、排序和笔记列表。

  • 笔记本一行最右边的「＋」可以新建笔记本，名称最多 12 个字，不能重名。
  • 长按自己建的笔记本，点「删除笔记本」可以删除；里面的笔记会自动转到「全部笔记」，不会丢。「全部笔记」和内置的四个笔记本不能删。
  • 点蓝色的标签只看带这个标签的笔记，再点一次取消。笔记本和标签二选一：选标签时笔记本回到「全部笔记」，选笔记本时标签取消。
  • 右下角绿色「＋」新建笔记，会放进当前选中的笔记本。
  • 搜索框可以按标题和正文找笔记。
  • 排序支持「最近更新」「按创建」「按标题」。
  • 列表顶部两张固定卡片：快同步（多台设备快速共享的一篇笔记）和 快任务（跳到任务页，角标是逾期数量）。
  • 被置顶的笔记会排在最前面，并带有图钉标记。

写笔记

点开一篇笔记即可编辑。标题下面是笔记本和标签，再下面是格式工具栏，选中文字后点对应按钮。

要给笔记加标签：点右上角 ⋮ →「添加标签」，输入名称，或直接点下面「已有标签」里的一个。同一篇笔记里标签不能重复。

按钮作用
正文 / H1 / H2 / H3切换段落样式
引用、代码块再点一次恢复成正文
无序列表 / 有序列表连续点击循环：正文 → 一级 → 二级 → 正文。无序是实心点 → 空心圈，有序是 1. → a.
B / I / U / S加粗、斜体、下划线、删除线
文字颜色、背景颜色从色板里选一个颜色
链接、图片、表格插入链接；从相册选图片；插入表格

右上角图标：

  • 循环箭头：用云端这一篇覆盖本地内容，适合在别的设备改过之后拉最新版。
  • 保存图标：本篇有未保存的改动时出现，点一下先存到本机，再上传到网盘。
  • 同步或保存进行中，图标会转圈。

编辑中也会定时自动保存并上传，离开笔记时会把没传的内容补传。右上角「⋮」里可以删除笔记，删除后进入回收站。

Markdown 格式的老笔记在手机上是只读的；用 Mac / Windows 端写的富文本笔记，手机上可以直接编辑。

表格

点工具栏里的表格图标，选好行数和列数就能插入一张表。

  • 点进格子就可以输入文字。
  • 表格会保存为通用格式，在 Mac / Windows 端打开样式一致。

快任务

底部「任务」页管理待办。任务按状态分组：待完成、进行中、已完成、已终止。

  • 输入框写标题，回车或点「添加」就新建一条；点旁边的图标可以在新建时一并填写日期和备注。
  • 点一条任务可以修改标题、备注和计划日期；已完成、已终止的任务可查看但不能改。
  • 过了计划日期还没完成的任务会标为逾期，底栏「任务」图标上会显示逾期数量。
  • 右上角循环箭头可以马上同步任务。

同步

平时不用守着，这些时候会自动同步：

  • 打开应用后，以及前台使用时每 45 秒一轮。
  • 切到「笔记」或「任务」页时。
  • 编辑笔记时定时上传（普通笔记约 30 秒，「快同步」约 15 秒）。
  • 切到后台时，把没传的笔记和任务补传。

想看详情，去「我的 → 同步与存储」：能看到最近一次同步、待上传的内容和云端目录，也可以手动再同步。

同步失败不会丢内容，写好的笔记仍在手机上，网络恢复后会自动重试。

我的

  • 账号卡：显示当前百度账号，点击可更换头像。
  • 同步与存储：同步状态、云端目录、重新授权。
  • 登录设备：查看登录过同笔记的设备，可以让其他设备下线。
  • 回收站：删除的笔记先在这里，可以恢复或彻底删除。
  • 关于与帮助：版本信息和这份使用说明。
  • 退出登录：清除本机授权，网盘里的笔记不受影响。

常见问题

换了手机怎么办？
用同一个百度网盘账号登录，笔记和任务会自动同步下来。

同步失败怎么办？
先检查网络；到「我的 → 同步与存储」手动再同步一次。仍失败可以点「重新授权」。

笔记存在哪里？
在你网盘的 /apps/tong_log 目录，笔记是 JSON、正文是受控 HTML、图片是普通图片文件，可以用百度网盘 App 直接查看或导出。

误删了笔记？
到「我的 → 回收站」恢复。

授权过期了？
到「我的 → 同步与存储」点「重新授权」。
