01登录

移动端登录页。品牌区与 Mac 端保持同一绿色渐变与卖点文案，操作区改为底部上滑卡片（sheet），单手即可触达。
功能点映射：A-01 登录态路由 · A-02/A-03 两种授权入口 · A-05 授权参数 · A-06 token · A-13 登录中状态
  • 授权方式适配：「系统授权窗口 / 浏览器扫码」改为「唤起系统浏览器或百度 App 完成 OAuth 回调」，回调经 tongnote://oauth/callback 回 App。
  • 扫码登录降级：移动端自己无法扫自己，扫码仅作为「用另一台设备扫此屏」的备用，主路径是「一键授权跳转」。
  • 品牌一致：沿用 Mac 的绿色渐变、品牌图标、三句卖点与隐私声明，保证跨端识别度。
  • 目录文案更正：统一写 /apps/tong_log（Mac 稿页脚曾误写 worklog）。

02笔记（首页）

底部 Tab「笔记」为首页。Mac 的「三栏并排」重构为「单栏列表 + 顶部横向筛选 + 右下角 FAB」。
功能点映射：N-02 三栏→底部导航 · B-06 新建笔记→FAB · B-07/C-05 笔记本筛选 · L-01/L-02/L-03 固定卡片 · L-04 搜索 · L-05 排序 · L-07 置顶 · L-08 右键→长按菜单
  • 三栏 → 底部 Tab：侧栏（笔记本/标签/回收站）拆分为「笔记 Tab 顶部 chips」+「我的 Tab 入口」，编辑器独立成页。
  • 侧栏按钮 → FAB：新建笔记由右上角圆形「＋」悬浮按钮承载，符合拇指热区。
  • 右键菜单 → 长按：置顶 / 删除（回收站为恢复 / 彻底删除）由右键改为长按卡片弹出 Action Sheet。
  • 保留能力：搜索、三种排序、置顶图钉、标签胶囊、每条笔记下方发丝分割线、固定卡片（快同步 / 快任务）全部保留。

03编辑器

全屏编辑页。Mac 顶部 16 项工具栏重构为「键盘上方横向滚动的格式条」，贴合拇指操作；表格交互从 hover 改为点选。
功能点映射：E-01 标题 · E-02 笔记本 · E-03 标签 · E-06 字数 · F-01~F-11 富文本 · LI 列表 · I 图片 · T-01~T-14 表格
  • 工具栏 → 底部格式条：T 样式 / B / I / U / S / 字号 / 文字色 / 背景色 / 列表 / 引用 / 代码 / 链接 / 图片 / 表格，横向滚动，与系统输入法键盘同时出现。
  • 表格 hover → 点选：桌面端「边沿灰圆 hover 变蓝加号」在触屏不可用，改为「点选单元格 → 弹出底部 sheet 菜单」，对齐 / 背景色 / 增删行列 / 删除表格全收进该菜单（右侧已示意）。
  • 选中文字 → 格式浮层：移动端恢复「选中即浮出格式条」比点击工具栏更自然（Mac 端该浮窗当前关闭，移动端建议启用）。
  • 保留能力：四级标题 40/32/24/18、正文 14pt、列表 Tab 层级、编号顺延、图片 480 上限、表格固定 100pt 列宽 + 匹配笔记宽度。

04任务

底部 Tab「任务」对应 Mac 的「快任务」。四状态分组 + 底部固定快捷添加。
功能点映射：TD-01 任务页 · TD-02 快捷添加 · TD-03 四状态流转 · TD-04 筛选 · TD-05 折叠 · TD-06/TD-07 统计与逾期 · TD-11 同步
  • 底部快捷添加：输入框固定在底部，回车即建，替代 Mac 的「输入框 + 添加按钮」。
  • 状态流转：点圆圈完成 / 取消完成；「开始 / 完成 / 终止 / 恢复」按钮置于行右侧。
  • 展开详情 → 全屏编辑页：备注富文本与截止时间不再行内展开，改为点击任务进入独立页（复用编辑器 + 日期选择器）。
  • 逾期表现：红字 + 浅红底胶囊，统计串与排序保持一致。

05我的

底部 Tab「我的」承接 Mac 侧栏底部与设置面板的个人信息、存储与入口。
功能点映射：AV 头像 · B-10 存储计量 · B-09/R 回收站 · D-03/D-04 设备管理 · SE 设置 · A-11 退出登录
  • 账号卡：头像 + 昵称 + 百度账号 + 同步状态绿点（点头像进头像选择）。
  • 存储卡：已用 / 总量 + 进度条，延续 Mac 右侧栏。
  • 入口收拢：同步与存储 / 登录设备 / 回收站 / 关于帮助 统一为列表项，替代 Mac 分散在侧栏与 sheet 的入口。
  • 退出登录：独立红色按钮，二次确认（只清凭证，不清本地笔记）。

06同步与存储

Mac 的「同步与存储」sheet 双栏重构为单栏滚动卡片。
功能点映射：SE-01 同步状态 · SE-02 云端目录 · SE-03 账号安全 · SE-04 登录设备 · SE-05 存储空间 · S-05/S-10 手动同步与状态
  • 双栏 → 单栏滚动：主区四卡 + 右侧栏（存储/数据说明）合并为纵向卡片流。
  • 同步状态：自动同步开关、最近同步、立即同步按钮；状态徽标四色（待同步/同步中/已同步/失败）。
  • 目录树更准确：补上 Mac 稿遗漏的 todos/、devices/、avatar.json，并修正为 notes/*.json 按篇存储。
