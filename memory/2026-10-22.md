# 2026-10-22 工作日志

## WorkLog 跨端笔记 App 设计（Mac UI + 数据格式）
- 用户计划自研「类印象笔记」笔记应用，替代收费的印象笔记；支持 Mac + Android，数据存于百度网盘固定目录 `/apps/WorkLog`，登录走百度网盘 OAuth。
- 交付：`WorkLog-Mac端UI设计.html`（自包含浅色主题设计稿，含登录页/主界面三栏/同步与存储三个可切换屏幕）。
- 数据格式方案：一笔记一文件（Markdown + YAML front-matter 存元数据）；`manifest.json` 作本地索引缓存；附件隔离 `assets/{noteId}/`；`.meta/sync_state.json` 存增量同步游标；删除入 `trash/`；冲突用修订号 rev 判大小、相等生成 `*.conflict-{time}.md`；token 存 Keychain/Keystore。
- 设计系统规范要点（来自 ardot 设计系统）：无纯黑、单一去饱和强调色（绿 #1a9e5c）、SF/PingFang 字体、禁止 3 等分卡片。
