# 百度网盘开放平台接入指南

> 同笔记 App 已内置 OAuth 授权码登录流程，只需按下面三步注册应用、填入凭证即可跑通真实登录。

## 一、注册应用（一次性）

1. 打开百度网盘开放平台：<https://pan.baidu.com/union>
2. 用百度账号登录，点击【快速接入】进入控制台。
3. 完成开发者认证（个人实名或企业认证）。
4. 创建应用，填写应用名称/分类/描述（桌面软件类目即可）。
5. 创建成功后，在**应用详情页**拿到凭证：
   - **AppKey**（即 `client_id` / API Key）
   - **AppSecret**（即 `SecretKey` / SK）
   - （AppId、SignKey 本应用暂不需要）

## 二、配置授权回调地址

1. 进入应用详情页 → **【安全设置】**。
2. 在「授权回调地址 / redirect_uri」中新增一条：

   ```
   tongnote://oauth/callback
   ```

   ⚠️ 必须与代码里的 `BaiduPanConfig.redirectURI` **完全一致**（含大小写、`://` 结构）。若不一致，授权成功后无法回调。

## 三、填入凭证

编辑 `Sources/WorkLogCore/BaiduPanConfig.swift`：

```swift
public static let appKey = "你的AppKey"
public static let appSecret = "你的AppSecret"
```

## 四、重新构建并运行

```bash
./scripts/build_app.sh release
open "同笔记.app"
```

## 五、验证登录

1. 点击「使用百度网盘账号登录」→ 系统弹出百度授权页。
2. 用百度账号登录并点击「授权」。
3. 授权成功自动回到主界面；进入「同步与存储」可见**真实账号名与网盘配额**。

## 已实现的技术细节

| 项 | 说明 |
|---|---|
| 授权模式 | OAuth 2.0 授权码模式（authorization_code） |
| 授权端点 | `https://openapi.baidu.com/oauth/2.0/authorize` |
| Token 端点 | `https://openapi.baidu.com/oauth/2.0/token` |
| 授权范围 | `basic,netdisk` |
| 授权载体 | 系统 `ASWebAuthenticationSession`（无需内嵌 WebView） |
| 回调方式 | 自定义 URL Scheme `tongnote://oauth/callback` |
| Token 存储 | Keychain（`BaiduPanTokenStore`），access_token 30 天 |
| 自动续期 | 过期前用 refresh_token 自动刷新（`BaiduPanClient.refresh`） |
| 账号信息 | `https://pan.baidu.com/rest/2.0/xpan/nas?method=uinfo` |
| 配额查询 | `https://pan.baidu.com/rest/2.0/xpan/nas?method=quota` |
