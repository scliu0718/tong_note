## 1. 产品是什么

### 1.1 一句话

**同笔记**是一款把笔记直接写进**你自己的百度网盘**的 macOS 笔记应用：不用订阅、不锁数据、没有中间服务器，笔记以开放格式保存，随时可以查看、导出、迁移。

### 1.2 三个核心承诺

| 承诺 | 具体含义 |
|---|---|
| 数据属于你 | 笔记、任务、图片附件都存放在你自己百度网盘的 `/apps/tong_log` 目录里，App 只读写这个目录，不读取你网盘中的其他文件 |
| 格式开放可迁移 | 笔记正文是受控 HTML、笔记与任务是 JSON、图片是普通图片文件；可以用任意文本编辑器打开，也能在百度网盘 App 里查看、导出 |
| 离线可用，联网自动同步 | 先写到本机磁盘，联网后自动做增量同步；同步失败不会退出登录、不会清空本地笔记，下一轮自动重试 |

### 1.3 主要功能一览

- **笔记**：富文本编辑（四级标题、加粗/斜体/下划线/删除线、字号、文字色/背景色、引用、代码块、链接）、有序/无序列表与层级、图片粘贴与插入、**表格**（对齐、背景色、增删行列、单元格菜单）。
- **组织**：笔记本（内置 4 个 + 自建）、标签、搜索、三种排序、置顶、回收站（可恢复 / 彻底删除）。
- **快任务**：四状态分组（待完成 / 进行中 / 已完成 / 已终止）、截止时间与日历、逾期提醒、富文本备注（可插图）、统计。
- **同步**：按篇同步，启动 / 每 45 秒 / 回到前台 / 保存后 1.5 秒 / 手动按钮都会同步；单篇「快同步」用于多台设备快速共享。
- **账号与安全**：百度网盘 OAuth 2.0 两种登录方式（系统窗口 / 浏览器扫码）、登录设备管理与手动下线。
- **个性化**：三档侧栏宽度、8 个预设头像（可跨设备同步）。

### 1.4 适合谁 / 不适合谁

| 适合 | 不适合 |
|---|---|
| 已经有百度网盘账号、希望笔记数据自己掌控的人 | 需要多人实时协作编辑同一篇笔记 |
| 在 Mac 与 Android 之间同步笔记、任务的人 | 需要深色模式、需要完整 Markdown 语法 |
| 喜欢富文本 + 表格 + 图片混排记录工作日志的人 | 需要批量操作、拖拽排序、复杂快捷键体系 |
| 接受「先本地、后云端」的自动同步节奏 | 需要毫秒级多端实时同步 |

## 2. 五分钟上手

### 第 1 步：打开 App

双击 `同笔记.app`。首次打开会看到登录页（左侧绿色品牌区，右侧登录区）。

### 第 2 步：登录百度网盘

两种方式任选其一：

- **使用百度网盘账号登录**：点绿色主按钮，在弹出的系统授权窗口里完成授权。
- **浏览器扫码登录**：点「浏览器扫码登录」，系统会打开默认浏览器；在授权页切换到「扫码登录」，用百度 App / 百度网盘 App 扫一扫，授权完成后会自动回到同笔记。

> **注意**：登录即代表你授权同笔记通过百度网盘开放平台读写 `/apps/tong_log` 目录。授权信息（token）只保存在本机。

### 第 3 步：新建第一篇笔记

点侧栏顶部的绿色「＋ 新建笔记」按钮 → 中间列表出现一篇新笔记并自动打开编辑器 → 在「笔记标题」处输入标题 → 在正文区开始写。

**什么都没点「保存」？** 同笔记是自动保存的，输入即写入本机；标题区会显示「已保存到本地」。

### 第 4 步：试一下格式

- 选中一段文字，点工具栏 **B** 加粗，或点「T」选择「一级标题」。
- 点工具栏 `tablecells` 图标，在网格上划选行列，插入一张表格；把光标放进格子，右上角会出现下箭头，点开可以设背景色。
- 截一张图（`Ctrl+Cmd+Shift+4` 复制到剪贴板），回到编辑器按 `Cmd+V`，图片会直接进笔记。

### 第 5 步：同步

点笔记列表底部的绿色「一键同步」按钮，或点侧栏齿轮 →「同步与存储」→「立即同步」。成功后状态变「已同步」，并显示时间。

> **提示**：其实不同步也会自动同步——启动时、每 45 秒（App 在前台时）、回到前台、以及你停止输入约 1.5 秒后都会跑一轮。

### 3.1 侧栏三档宽度

| 档位 | 宽度 | 显示内容 |
|---|---|---|
| 极窄 | 52 | 只有图标；鼠标停在图标上会在光标下方浮出名称与篇数 |
| 窄（默认） | 112 | 图标 + 文字竖排 |
| 宽 | 200 | 横排完整信息 |

切换方式（三种，任选）：
1. **拖动**侧栏与列表之间的分隔条（会吸附到最近一档）。
2. **点击**分隔条任意位置。
3. 点击分隔条中部的 **`>` / `<` 箭头**。

顺序是「极窄 → 窄 → 宽 → 极窄」循环。分隔条上只有一个箭头，没有方块底。

> **提示**：极窄档时把鼠标停在笔记本/标签/回收站图标上，会看到名称和「N 篇笔记」的说明浮窗。

### 3.2 侧栏各区

| 区 | 能做什么 |
|---|---|
| 顶部账号区 | 点头像换头像；点齿轮打开「同步与存储」设置 |
| 「＋ 新建笔记」 | 新建一篇笔记（宽档显示文字，窄/极窄显示圆形＋） |
| 笔记本区 | 「全部笔记」+ 内置 4 个（工作日志 / 读书笔记 / 投资研究 / 灵感速记）+ 你自建的笔记本；右键可新建/删除自建笔记本 |
| 标签区 | 点标签筛选笔记；右键可删除标签 |
| 底部 | 回收站（带数量）、本地存储计量（「N 篇笔记」） |

> **限制**：侧栏里**没有**任务分区和设置分区。「快任务」入口在笔记列表顶部的固定卡片；设置在顶部齿轮。侧栏里的「老王的工作台」是固定展示文案，不是你的百度账号名；真实账号名在设置面板里看。

### 3.3 内容区

- 点笔记 → 编辑器。
- 点「快任务」卡片 → 任务页。
- 点任意笔记会自动退出任务页。
- 没选中任何笔记时显示「选择或新建一篇笔记」。

## 4. 登录、账号与授权

### 4.1 两种登录方式

| 方式 | 操作 | 适用场景 |
|---|---|---|
| 系统授权窗口 | 点「使用百度网盘账号登录」→ 在弹出窗口完成授权 | 常规登录 |
| 浏览器扫码 | 点「浏览器扫码登录」→ 浏览器授权页切到「扫码登录」→ 用百度/百度网盘 App 扫码 → 自动跳回 App | 不想在系统窗口输密码、或想用手机扫码 |

授权完成后 App 会自动进入主界面，并立即开始第一轮同步。

> **注意**：没有「手动粘贴授权码」或账号密码登录入口。如果授权窗口被取消，会提示「已取消登录」，重新点按钮即可。

### 4.2 重新授权与退出登录

打开侧栏齿轮 →「同步与存储」→「账号与安全」：

- **重新授权**：点「重新授权」会走浏览器扫码流程，用于授权过期或换账号。
- **退出登录**：点「退出」。**只会清除登录凭证**（token 和账号信息），**不会删除本机笔记**，也不会删除设备编号。下次登录还能看到原来的笔记。

### 4.3 被其他设备下线

如果你在设置面板里把某台设备点了「下线」，那台设备**下次打开 App、回到前台、或进行同步时**会自己退出到登录页，并显示「本机已在其他设备被下线，请重新登录」。

- 下线**不要求对方在线**。
- 对方**离线写下的、还没同步的笔记仍留在那台设备上**，不会丢。
- 被下线的设备**重新登录一次即可继续使用**。
- 只有登录凭证被清掉，本机笔记不清空。

> **注意**：同笔记**不会**因为「新设备登录」自动把旧设备挤下线；下线需要你在设备列表里手动操作。

## 5. 笔记本、标签与笔记管理

### 5.1 新建笔记

点侧栏「＋ 新建笔记」。新笔记默认归属「工作日志」（当你在某个具体笔记本下新建时，归到该笔记本），并自动打开编辑器。

> **限制**：没有 `Cmd+N` 快捷键，只能用按钮新建。

### 5.2 归属与标签

在编辑器标题区：

| 操作 | 怎么做 |
|---|---|
| 换笔记本 | 点标题下方的笔记本名 → 下拉菜单里选一个 |
| 加标签 | 点标签行右侧的「＋」→ 输入标签名 →「添加」 |
| 移除标签 | 点标签胶囊上的 `×` |

在侧栏右键标签 →「删除标签」，会把这个标签从**所有笔记**上移除，但笔记和正文都保留。

### 5.3 笔记本管理

- **新建**：在侧栏笔记本区右键 →「新建笔记本」→ 输入名称 →「创建」。
- **删除**：只对自己新建的笔记本有效，右键 →「删除该笔记本」。该笔记本下的笔记会**自动转移到「全部笔记」**，笔记本身不会丢。
- **不能删**：「全部笔记」和内置的 4 个笔记本。

**名称规则**：不能为空、不能叫「全部笔记」、不能重名、**最多 12 个字**。不满足时会弹出具体原因。

### 5.4 搜索与排序

| 功能 | 位置 | 说明 |
|---|---|---|
| 搜索 | 笔记列表上方搜索框 | 匹配标题或正文内容（不区分大小写）；右侧 `×` 清空 |
| 笔记本筛选 | 点侧栏笔记本 | 只看该笔记本 |
| 标签筛选 | 点侧栏标签 | 只看含该标签的笔记 |
| 排序 | 「最近更新」「按创建」「按标题」 | 点文字切换 |

> **注意**：进入回收站后，搜索/笔记本/标签过滤**不再生效**，但搜索框仍然显示、可以输入。这不是输入没反应，是回收站视图按设计跳过了过滤。

### 5.5 笔记卡片与置顶

卡片显示：标题（置顶有图钉）、两行摘要（富文本会剥掉标签只留文字，最多 60 字，空笔记显示「空笔记」）、时间（今天/昨天 `HH:mm`，更早显示 `M月d日`）、标签胶囊。每篇笔记下面都有一条很浅的分割线。

**右键菜单**：

| 场景 | 菜单项 |
|---|---|
| 正常 | 置顶笔记 / 取消置顶笔记 · 删除笔记（移入回收站） |
| 回收站 | 恢复笔记 · 彻底删除笔记 |

> **限制**：置顶**只在「最近更新」排序下有效**（因为置顶会刷新更新时间）。切到「按创建」或「按标题」时，置顶笔记不会固定在最前。

### 5.6 回收站

1. 点侧栏底部「回收站」进入。
2. 此时编辑器是**只读**的：工具栏隐藏、标题不能改、笔记本与标签不可编辑。
3. 右键卡片或点标题区右上角按钮：**恢复笔记** / **彻底删除**（彻底删除会二次确认「此操作不可恢复，笔记将被永久移除」）。

> **提示**：彻底删除后，笔记会留一条「墓碑」记录用于让其他设备知道它被删了，界面不再显示；对应的图片附件会在确认没有其他笔记引用后被清理。

## 6. 编辑器：写笔记

### 6.1 工具栏完整对照

| 图标 | 名称 | 作用 |
|---|---|---|
| `T ▾` | 文本样式 | 正文 / 一级~四级标题 / 有序列表 / 无序列表 |
| `B` | 加粗 | 选中文字加粗 |
| `I` | 斜体 | 选中文字斜体 |
| `U` | 下划线 | 选中文字下划线 |
| `S` | 删除线 | 选中文字删除线 |
| `字号 ▾` | 字号 | 12 档：11/12/13/14/15/16/18/20/24/28/32/40 |
| 橙色 `A ▾` | 文字颜色 | 9 色色板 + 「自定义」取色器 |
| 画笔 ▾ | 背景颜色 | 9 色色板 + 「自定义」+「清除背景色」 |
| 引号 | 引用 | 整段变引用（左右缩进 20） |
| `</>` | 代码块 | 整段变等宽代码块 |
| 回形针 | 插入链接 | 输入链接地址与显示文字（可留空） |
| 图片 | 插入图片 | 打开文件选择面板挑一张图 |
| 表格 | 插入表格 | 划选行列插入；表格内还会多出 5 个命令 |
| 对齐 ▾ | 单元格对齐 | **只在光标位于表格内时出现**：左 / 居中 / 右 / 两端 |
| `N 字` | 字数 | 只读统计 |
| 垃圾桶 | 删除笔记 | 移入回收站（会二次确认） |

> **提示**：鼠标停在任意工具按钮上，会在按钮上方浮出黑色小气泡说明，同时系统 tooltip 也可作为兜底。

### 6.2 标题与正文

「T」菜单里：

| 样式 | 字号 | 是否加粗 |
|---|---|---|
| 正文 | 14 | 常规 |
| 一级标题 | 40 | 加粗 |
| 二级标题 | 32 | 加粗 |
| 三级标题 | 24 | 加粗 |
| 四级标题 | 18 | 加粗 |

> **注意**：把一段文字**切回正文或列表时，会自动清除继承的粗体并重置字号**（斜体会保留）。这是为了保证标题不会「污染」后面的正文。切完之后你仍然可以手动再加粗、改字号、改颜色。
> **注意**：字号菜单里当前默认勾选的是 15，而正文实际是 14pt，这是界面上的一个小不一致，以文字实际大小为准。

### 6.3 列表

- 点「T」→「有序列表」或「无序列表」开始列表。
- **有序编号体系**：`1. 2. 3.` → 子级 `a. b. c.` → 再子级 `i. ii. iii.`。
- **无序圆点**：父级实心蓝色 `•`，子级同样大小的空心圆点（同一字形、只描边），层级靠缩进区分。
- **调整层级**：在列表行按 `Tab` 提升层级、`Shift+Tab` 降低层级；再次点同一个列表按钮也能提升一级。
- **退出列表**：把光标放到该行内容最前面，按一次 **退格**，这一行变回正文，编号会自动重排。
- **回车**：新行自动继承上一行的层级和编号体系。

> **提示**：在列表中间插了一段正文、再手动把下面恢复成列表时，只要中间**只隔一段正文**，编号会顺延上方的列表，不会重新从 1 开始。
> **限制**：表格单元格里不能用列表（编号/圆点与表格边框会抢同一套排版）。

### 6.4 引用、代码块、链接

- 选中段落后点「引用」或「代码块」，整段切换样式；再点一次「T」→「正文」可切回。
- 「插入链接」：填链接地址（默认预置 `https://`）和显示文字（可留空，留空则用地址本身）。填了无效地址会提示「请输入有效的链接地址」。

### 6.5 老笔记（Markdown）会怎样

早期版本或外部导入的 Markdown 笔记，第一次在编辑器打开时会按简化规则渲染（识别 `#` 标题、`-` 列表、`>` 引用、加粗/斜体/删除线/行内代码/链接）。**你一开始编辑，正文就会升级为富文本格式并自动保存**。

> **限制**：这个兼容转换是有损简化的 —— 代码围栏行会被丢弃、标题只保留到三级、连续普通行会合并成一段、只有指向 `attachments/` 的图片才会变成真实图片。重要历史笔记建议先复制一份再编辑。

## 7. 编辑器：表格

表格是同笔记里交互最丰富的一块，按下面顺序看一遍就能上手。

### 7.1 插入表格

1. 点工具栏 `tablecells` 图标。
2. 在弹出的网格上移动鼠标，顶部会显示「插入 N 行 × N 列」（最多 6 行 × 8 列）。
3. 点击即插入。

> **注意**：新建的表格**每列固定 100pt，不会铺满整篇笔记**。想让它铺满，见 7.5「匹配笔记宽度」。

### 7.2 在格子里移动与新增行

| 操作 | 效果 |
|---|---|
| `Tab` | 跳到下一格 |
| `Shift+Tab` | 跳回上一格 |
| 在**最后一格**按 `Tab` | 自动新增一行 |

### 7.3 边沿的小灰圆（增加行 / 增加列）

表格**顶边上方**和**左边外侧**各有一排常驻的小灰圆：

- 鼠标移到灰圆上 → 变成**蓝色实心圆 + 白色加号**，同时出现一条蓝色引导线与表格边线重叠，光标变成「可点击的手型」。
- **点这个「+」图标本身**即可增加一列（顶边）或一行（左边）。
- 蓝圆/灰圆与表格竖线、横线是**对齐重叠**的，不需要刻意偏移去点。

> **注意**：**只允许点击「+」图标来增加行和列**，点它旁边的空白区域不会生效。这是刻意设计，避免误触。
> **限制**：最多 100 行、32 列。到达上限时会听到一声提示音，不会再增加（日志里也会写明上限）。如果你点「+」没反应，先确认是不是已经到上限，或查看 14.4 的排查方法。

### 7.4 单元格右上角的下箭头

把光标放进任意格子，格子右上角会出现一个 **16pt 下箭头**，点开弹出菜单：

| 菜单项 | 作用 |
|---|---|
| 单元格背景（20 色色板） | 第一格白圆带斜杠 = 无颜色，其余 19 色任选；可给**多个选中格子**一起上色 |
| 匹配笔记宽度 | 勾选后表格铺满编辑区；取消则回到每列固定 100pt |
| 删除选中的列 / 删除选中的行 | 删当前列 / 行 |
| 删除表格 | 整张表删掉 |

### 7.5 对齐与宽度

- **工具栏「对齐」按钮**（光标在表格内时才出现）：左 / 居中 / 右 / 两端对齐。
- **单元格菜单「匹配笔记宽度」**：切换满宽 / 固定列宽。
- 设置对齐、背景色、宽度**都不会改变你已经调好的列宽**，也不会打断正在输入的文字。

> **提示**：把鼠标移到表格竖边会出现左右拖动光标、横边会出现上下拖动光标，可以拖着调整列宽/行高。

### 7.6 表格内的工具栏命令

光标在表格内时，再点 `tablecells` 图标，浮层底部会多出 5 项：**在下方插入行 / 在右侧插入列 / 删除当前行 / 删除当前列 / 删除表格**。

### 7.7 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 新建表格太窄 | 设计如此（每列 100pt）。用单元格菜单勾「匹配笔记宽度」 |
| 设完背景色表格突然变宽 | 已修复；当前版本设置单元格属性不会重建表格、不会改宽度 |
| 点「+」没反应 | 只认「+」图标本身，稍靠近圆心点；或已到行列上限；详见 14.4 |
| 表格里按 Tab 没跳格 | 确认光标确实在单元格内；表格里不支持列表 |

## 8. 编辑器：图片与截图

### 8.1 三种把图放进笔记的方法

| 方法 | 操作 |
|---|---|
| **截图直接粘贴** | 用 `Ctrl+Cmd+Shift+4` 截图（**带 Ctrl 才会进剪贴板**）→ 回编辑器 `Cmd+V` |
| **复制已有图片再粘贴** | 在任何地方拷贝图片 → 回编辑器 `Cmd+V`（也支持「粘贴并匹配样式」菜单） |
| **从文件插入** | 点工具栏「插入图片」→ 在文件面板里选一张图 |

> **注意**：`Cmd+Shift+4`（不带 Ctrl）是**把截图存成文件**，不会进剪贴板，此时 `Cmd+V` 粘不到图。存成文件的截图请用「插入图片」按钮选文件。

### 8.2 从笔记里复制图片

在笔记里选中一张图，右键「拷贝」（或 `Cmd+C`）→ 到别处 `Cmd+V`。同笔记会往剪贴板写入标准 PNG 数据，避免只写入 AppKit 私有的 RTFD 包导致别的程序识别不了。

### 8.3 支持哪些图片

`png / jpg / jpeg / gif / webp / heic / heif / tiff / tif / bmp` 共 10 种。粘贴时会自动识别剪贴板里的图片数据并落盘；落盘后还会**立刻验证能否被系统读图引擎打开**，读不出就自动统一转成 PNG 再试。

### 8.4 图片会存在哪

图片会被复制到本机 `~/Library/Application Support/tonote/attachments/<笔记ID>/` 下，**正文里只记录相对路径**，同步时按同样的相对路径上传到你网盘的 `/apps/tong_log/attachments/`。所以换设备同步后图片依然能正确指向同一份文件。

- 插入的图片最大显示宽度 480pt，会等比缩放。
- 图片和文字在同一段落里，可以图文混排。
- 如果粘贴的是「本地图片路径文本」（例如从微信/备忘录复制的一串路径），同笔记会自动识别并把它替换成内联图片，其余文字保留。

### 8.5 粘贴失败怎么办

同笔记**不会**在粘贴失败时悄悄退化成系统默认粘贴（那样会插入临时引用，保存后图片就丢了）。失败时会弹「操作失败」，并说明剪贴板里实际有哪些类型，通常会建议你改用工具栏「插入图片」选择截图文件。

> **提示**：如果粘贴一直不成功，可查看 `~/Library/Application Support/tonote/paste-debug.log`，里面按时间记录了整个粘贴链路（前缀 `[TNPaste]`）。

## 9. 快任务（任务面板）

### 9.1 打开与命名

点笔记列表顶部的「快任务」固定卡片进入任务页。列表卡片叫「快任务」，页面顶部标题叫「任务」，是同一个功能。卡片副标题会显示「待完成 N · 进行中 N」，有未完成任务时右侧有绿色数字角标。

### 9.2 添加任务

在页面底部输入框写任务名，**按回车**即可创建；也可以点「添加」按钮。

### 9.3 四个分组与状态流转

| 分组 | 可用操作 |
|---|---|
| 待完成（红） | 「开始」→ 进行中；「终止」→ 已终止；点圆圈直接标记完成 |
| 进行中（琥珀） | 「完成」→ 已完成；「终止」→ 已终止 |
| 已完成（绿） | 点圆圈可「取消完成」 |
| 已终止（灰） | 「恢复」→ 回到待完成 |

顶部筛选可切「全部」/「仅未完成」；选「仅未完成」时，已完成和已终止两组不显示。点分组标题可以折叠/展开。

顶部统计串形如「待完成 3 · 进行中 1 · 已完成 5 · 终止 1 · 逾期 2」。

### 9.4 展开一条任务

点任务行（或右侧展开箭头）会展开详情，**同一时刻只展开一条**。详情里可以：

- 写**富文本备注**（同样支持插入图片，工具栏在编辑器内）。
- 设置**截止时间**：勾「设置截止时间」→ 用年/月/日步进框调整，或点「日历」在弹出的月历里选日期（有「今天」快捷按钮）。
- 点「保存」收起。

> **提示**：展开编辑期间列表顺序是冻结的，改了截止时间行也不会突然跳位；收起后恢复排序并自动同步。

### 9.5 逾期

截止时间早于今天且任务未完成/未终止时，算逾期：日期胶囊变红字 + 浅红底，统计里出现「逾期 N」，排序时逾期优先。

### 9.6 删除任务与同步

- 每行右侧垃圾桶：删除任务（**没有回收站**，直接删除）。
- 页头「同步」按钮：同步全部笔记与任务。
- 页头常驻「上次同步 MM-dd HH:mm」/「尚未同步」。
- 任务任何改动都会在约 **1.2 秒**后自动触发同步。

> **限制**：当前版本**没有「清除已完成」按钮**，已完成/已终止的任务只能逐条删除。

## 10. 同步与多设备

### 10.1 什么时候会自动同步

| 时机 | 周期 |
|---|---|
| 打开 App | 立即 |
| App 在前台 | 每 45 秒 |
| 从后台回到前台 | 立即 |
| 保存/修改之后 | 停止操作约 1.5 秒 |
| 任务改动之后 | 约 1.2 秒（任务页自己的防抖） |

不需要手动点保存，也不需要手动点同步。

### 10.2 三个「同步」入口各做什么

| 入口 | 实际行为 |
|---|---|
| 笔记列表底部「一键同步」 | **全量同步**：所有笔记 + 笔记本 + 任务 |
| 设置面板「立即同步」 | **全量同步**（按钮文字随状态变：同步全部 / 同步中… / 再次同步 / 重试同步） |
| 「快同步」笔记右上角「同步」 | **只同步这一篇**（单篇同步，跳过笔记本和任务） |
| 任务页「同步」 | 全量同步 |

> **注意**：点笔记列表顶部的「快同步」**卡片**只是**打开这篇笔记**，不会发起同步。要同步请点开后右上角的「同步」按钮，或用「一键同步」。

### 10.3 「快同步」笔记是什么

它是一篇固定的特殊笔记，标题「快同步」，描述「多设备共享 · 一处编辑处处可见」，不归属任何笔记本（标题区会标「独立笔记 · 不归属任何笔记本」），也不参与笔记本筛选。

**典型用法**：在 A 电脑的「快同步」笔记里写内容 → 点右上角「同步」→ 在 B 电脑打开同笔记并同步一次 → B 就能看到相同内容。适合在两台设备间快速传一段文字。

### 10.4 同步状态怎么看

| 徽标 | 含义 |
|---|---|
| 待同步（灰） | 还没有同步记录，或有本地改动待上传 |
| 同步中（琥珀） | 正在拉取云端并对比，按钮会转圈并禁用 |
| 已同步（绿） | 上一轮成功，显示时间；`lastMessage` 形如「笔记 N 篇 · 任务 M 条」 |
| 同步失败（红） | 显示具体错误原因 |

**失败不会退出登录，也不会清空本地笔记**；下一轮会自动重试。离线时照常可以写笔记，联网后会自动补上。

### 10.5 冲突怎么处理

如果同一篇笔记在两台设备上都改过、且都还没同步，同步时会**保留两边的内容**：输的一方会被另存为一篇标题带「（冲突副本）」的新笔记。你可以事后自己比对合并。

> **提示**：尽量避免在两台设备离线时同时大改同一篇；如果产生了多份冲突副本，手动删掉多余的即可。

### 10.6 云端目录长什么样

你的百度网盘 `/apps/tong_log/` 下大致是：

```
/apps/tong_log/
  ├── notes/           每篇笔记一个 <UUID>.json（正文、rev、更新时间、删除/墓碑标记）
  ├── todos/           每条任务一个 <UUID>.json
  ├── attachments/     图片附件，按 <笔记或任务 UUID>/ 分目录
  ├── notebooks.json   自建笔记本与已删除笔记本名单
  ├── devices/         每台设备一个 <设备号>.json（登录会话与下线标记）
  ├── avatar.json      头像选择
  └── manifest.json    旧版本遗留的清单（仅首次迁移时读取，之后不再写）
```

> 设置面板里有一张「云端目录结构」卡片展示其中主要几项；`manifest.json` 与 `avatar.json` 未列在那张图上，但确实存在。

### 10.7 彻底删除后云端会怎样

彻底删除一篇笔记后，会在数据里留一条「墓碑」记录（标记 `purged`），让其他设备知道它被删了；**远端那篇笔记的 JSON 文件暂时不会立刻删掉**，但界面不再显示。确认没有其他笔记引用它的图片后，对应附件目录会被清理。

## 11. 设置面板与设备管理

点侧栏顶部 **齿轮** → 打开「同步与存储」（唯一一个设置窗口，尺寸 900×640）。

### 11.1 主区四张卡片

| 卡片 | 内容与可用操作 |
|---|---|
| **同步状态** | 同步范围（按篇存在 `/apps/tong_log/notes/`）、最近同步时间、状态徽标、「立即同步」按钮、成功/失败结果文字 |

| **登录设备** | 设备列表、「刷新」、每台设备的「下线」按钮 |

### 11.2 设备管理

- 列表里本机标「本机」，排在第一个。
- 其他设备点「下线」→ 二次确认「让这台设备下线？」→ 确认后按钮变「正在下线…」。
- 确认框会写明：「「设备名」下次打开或同步时会退出登录。已经写在那台设备上、还没同步的笔记会留在本地。」

- 点「刷新」重新读取云端设备清单。

### 11.3 右侧栏

- **存储空间**：已用 / 总量（以百度网盘为准）+ 进度条。
- **数据说明**：笔记为开放格式，可直接用文本编辑器打开，也可通过百度网盘 App 查看、导出或迁移。
- 底部标语：「同笔记 · 数据属于你自己 / 无需订阅 · 无服务器存储」。
- 左上角 `×` 关闭；`Esc` 也能关（这是系统默认行为）。

## 12. 头像

1. 点侧栏顶部头像 → 弹出「选择头像」。
2. 4 列网格里共 **8 个预设**（同 / 叶 / 笔记 / 书 / 笔 / 星 / 月 / 心），默认「同」。

## 14. 常见问题与故障排查

### 14.1 登录后一直「同步失败」

1. 看设置面板「同步状态」卡片里的红色失败文字，那里显示的是具体错误原因（例如百度接口错误、网络错误）。
2. 确认 Mac 能联网、百度网盘账号正常。
3. 失败不会退出登录、不会清数据；过一会儿会自动重试，也可点「重试同步」。
4. 如果提示授权相关，点「重新授权」走一遍浏览器扫码。

### 14.2 粘贴图片没反应 / 弹「操作失败」

- 确认用的是 **`Ctrl+Cmd+Shift+4`**（带 Ctrl 才进剪贴板）；`Cmd+Shift+4` 存的是文件，请用工具栏「插入图片」。
- 弹窗里会列出剪贴板实际类型，按提示改用「插入图片」选文件通常能解决。
- 想看细节：打开 `~/Library/Application Support/tonote/paste-debug.log`（前缀 `[TNPaste]`）。

### 14.3 表格「+」点了没反应

- 必须点**蓝色加号图标本身**（不是旁边空白）；鼠标移上去变手型、出现蓝圆和引导线时才算命中。
- 检查是否已经到上限：最多 **100 行 / 32 列**，到上限会有一声提示音。
- 想看命中细节：打开 `~/Library/Application Support/tonote/table-debug.log`（前缀 `[TNTable]`），里面记录了每次点击坐标、最近的圆点、距离与是否命中。

### 14.4 表格宽度/对齐看起来不对

- 新建表格默认每列 100pt、不铺满；需要铺满请在单元格菜单勾「匹配笔记宽度」。
- 设置对齐、背景色、宽度模式都**不会**改变你已经调好的列宽；如果你在很旧的笔记里遇到异常，重新打开一次笔记让排版重算即可。

### 14.5 搜索框输入没反应

确认是不是在**回收站视图**里 —— 回收站下搜索/筛选按设计不生效。回到正常笔记列表再搜。

### 14.6 置顶的笔记没有排在最前

置顶只在「最近更新」排序下生效。切到「按创建」或「按标题」时不会置顶。

### 14.7 换设备 / 重装后笔记还在吗

只要登录的是**同一个百度网盘账号**，同步后笔记、任务、笔记本与附件都会回来。注意：同步基线记录（`note-sync.json` / `todo-sync.json`）只存在本机、不上传，所以新设备首次同步会按「更新时间」做一次全量比对，这是正常现象。

### 14.8 被下线了，本地写的笔记会丢吗

不会。被下线只清登录凭证，本地笔记保留。重新登录后会继续同步。

### 14.9 App 打不开 / 更新后异常

- 确认 macOS ≥ 14.0。
- 完全退出再打开（可在活动监视器里结束「同笔记」进程后重新双击 App）。
- 本地数据在 `~/Library/Application Support/tonote/`，**不要手动删除这个目录**；如需排查，先整体复制一份备份再操作。

## 15. 我的数据在哪里 / 导出与迁移

### 15.1 本机文件

所有本机数据都在：

```
~/Library/Application Support/tonote/
```

| 文件 | 内容 |
|---|---|
| `notes.json` | 全部笔记（含回收站与墓碑） |
| `todos.json` | 全部任务 |
| `note-sync.json` / `todo-sync.json` | 同步基线对照表（只在本机，不上传） |
| `device.json` | 本机的设备编号与登录会话编号 |
| `baidupan-token.json` | 登录凭证（权限 0600） |
| `attachments/<UUID>/` | 图片附件（每篇笔记/任务一个目录） |
| `paste-debug.log` / `table-debug.log` | 粘贴 / 表格交互诊断日志 |

笔记本名单、头像选择、上次同步时间存在系统 `UserDefaults` 里。

### 15.2 云端文件

你的百度网盘 `/apps/tong_log/`（结构见 10.6）。同笔记只读写这个目录。

### 15.3 格式与导出

- 笔记与任务是 **prettyPrinted JSON**（日期 ISO8601），正文是**受控 HTML**（固定标签子集），图片是普通 png/jpg/... 文件，正文里只写相对路径。
- 因此你可以：用任意文本编辑器打开 JSON；在百度网盘 App 里查看/下载整个目录；把 `attachments/` 与 JSON 一起拷走即可完整迁移。
- 换设备时不需要手工导出，登录同一账号同步即可。

> **限制**：同笔记**没有本地自动备份/快照功能**，只有「原子写入」防止写一半损坏。重要数据建议自行定期复制 `~/Library/Application Support/tonote/` 或依赖百度网盘的版本/回收能力。

### 15.4 隐私与安全

- 百度开放平台凭证（AppKey / AppSecret / AppID）放在 App 包内，不进代码仓库；登录 token 存在本机且权限设为仅本人可读写。
- 笔记数据在本机是**明文 JSON**（和 token 同等安全等级）。如果本机有多用户或开启磁盘共享，请注意系统层面的访问控制。
- 退出登录只清 token，不删笔记、不删设备编号。

## 16. 当前版本的限制（诚实清单）

| # | 限制 | 说明 |
|---|---|---|
| 1 | 无深色模式 | 界面固定浅色配色，系统切深色后仍按浅色渲染 |
| 2 | 无 `Cmd+B/I/U`、`Cmd+N` 快捷键 | 加粗等请用工具栏；新建笔记用侧栏按钮 |
| 3 | 无批量操作 / 拖拽排序 | 笔记只能单条删除、置顶；不能拖到别的笔记本 |
| 4 | 置顶只在「最近更新」下生效 | 其余两种排序不判断置顶 |
| 5 | 回收站下搜索/筛选不生效 | 搜索框仍可见可输入 |
| 6 | 任务无回收站、无「清除已完成」 | 删除即生效；已完成/终止只能逐条删 |
| 7 | 表格单元格内不支持列表 | 编号圆点与表格边框冲突 |
| 8 | 表格上限 100 行 / 32 列 | 工具栏一次最多插 6 行 × 8 列 |
| 9 | 选中文字浮动格式窗口当前关闭 | 功能完整保留但未启用，请用工具栏 |
| 10 | 旧 Markdown 转换有损 | 代码围栏丢弃、标题只到三级、连续行合并 |
| 11 | 无本地自动备份 | 只有原子写入防损坏 |
| 12 | 同步冲突会产生「（冲突副本）」 | 需手动比对合并 |
| 13 | 设备下线是手动的，且被下线设备重新登录即可解绑 | 没有自动互踢 |
| 14 | 同步失败是「可重试降级」 | 不会阻断使用，也不会立刻弹强提醒；状态在设置面板/快同步笔记里看 |
| 15 | 侧栏「老王的工作台」是固定文案 | 真实账号名请看设置面板 |
| 16 | 只支持百度网盘 | 无其他云盘 / 本地任意目录 / WebDAV |
| 17 | 仅 macOS 14+ | 移动端为另一工程（数据格式按跨端一致设计） |

## 17. 附录：状态与提示语对照

| 你看到 | 意思 |
|---|---|
| 待同步 / 同步中 / 已同步 / 同步失败 | 四种同步状态（灰 / 琥珀 / 绿 / 红） |
| 同步全部 / 同步中… / 再次同步 / 重试同步 | 设置面板「立即同步」按钮随状态变化 |
| 一键同步 / 已同步 | 笔记列表底部按钮 |
| 已同步 HH:mm / 失败：… | 「快同步」笔记右上角状态 |
| 尚未同步 / 上次同步 MM-dd HH:mm | 任务页头部常驻 |
| 已保存到本地 | 编辑器标题区绿点（正常态） |
| 回收站中的笔记 | 编辑器标题区灰点（只读态） |
| 独立笔记 · 不归属任何笔记本 | 「快同步」虚拟笔记 |
| 多设备共享 · 一处编辑处处可见 | 「快同步」卡片描述 |
| 本机 / 已下线 / 下线 / 正在下线… | 设备列表状态 |
| 本机已在其他设备被下线，请重新登录 | 被下线后登录页提示 |
| 空笔记 | 正文为空时卡片摘要 |
| 今天/昨天 HH:mm、M月d日 | 笔记卡片时间 |
| 图片 | 任务备注只有图、没有文字时的预览 |
| 操作失败 | 编辑器统一错误弹窗（粘贴/插图/链接等） |
| 此操作不可恢复，笔记将被永久移除 | 彻底删除确认 |
| （冲突副本） | 同步冲突时自动生成的副本标题后缀 |
