四、尚未 1:1 的部分（如实说明）

  • 同步范围队列：Mac 有 SyncScope（谁点同步谁、笔记 30 秒 / 快同步 15 秒节流、切换笔记插队单篇拉取）。Windows 目前是「1.5 秒防抖全量 + 新增 45 秒轮询 + 单篇同步按钮」，语义接近但不等价。
  • 表格边沿 gutter：灰圆／蓝加号／引导线是 AppKit 自绘，Windows WebView2 版以工具条浮层替代，交互入口不同。
  • 列宽拖拽：模型层支持 data-widths，但两端 UI 都未提供拖拽手柄；Mac 也无。
  • SF Symbols 与 macOS 标题栏：Windows 第二轮已换成自绘线性矢量图标（轮廓按 SF Symbols 的极简风格重画，并非同一套字形），标题栏仍是 Windows 系统样式，不可能逐像素一致。
  • 使用说明内容：Mac 加载打包的 guide/index.html，Windows 用内建结构化说明窗口（内容按 Mac 功能点清单编写）。

五、UI 精致化（第二轮 · 针对「用着很粗糙」的反馈）

第一轮解决了「有没有」与「像不像」，但真实运行时仍有五处让界面显得廉价。定位结果与改法如下：

粗糙来源原因本轮改法
中文字体发虚、字重不一所有 TextBlock / Button 都没有指定字体族，Avalonia 回退到系统默认字体，中文接近宋体；设计稿的 font 变量只写进了 WebView 的 CSS，没进原生层。App.axaml 定义全局 TnFont = Microsoft YaHei UI, Segoe UI, Inter, …，Window / Button / TextBox / ComboBox / ToolTip / MenuItem 统一继承；编辑器 CSS 同步加 text-rendering: optimizeLegibility。
彩色 emoji 与豆腐块旧 Glyphs 用 🔖 / 🔗 / ☁ / ⌫ / 全角 ＋ 等字符，还试图用 Segoe MDL2 Assets 渲染，缺字时回退成彩色 Emoji 或方框。新增 Icons.cs：28 枚 24×24 描边矢量图标，统一 1.7 线宽、圆头圆角、单色可换色；Ui.Icon / Tool / Small / Chip / StateRing / EmptyState 与登录页勾点全部改走矢量，字母类工具按钮（B/I/U/S/T/字号）保留文字。
按钮 hover 变 WinUI 蓝代码式创建的 Button 使用 FluentTheme 默认 ControlTheme，:pointerover 蓝灰底、:pressed 深蓝、焦点虚线框，与 Mac 的克制风格冲突。自定义 TnButton ControlTheme：模板只做本地属性 TemplateBinding，hover/pressed 改为 0.12s 透明度过渡；TextBox 去掉蓝色 focus 边框，改主题绿光标 + 淡绿选区 + 淡绿细环；滚动条 9px、ToolTip 深色小气泡、右键菜单同字体。
界面「平」、没有层次旧代码用 BoxShadows.Parse 解析多阴影字符串，解析失败被 try/catch 吞掉并静默返回 default，所有卡片／浮层其实都没有阴影；笔记卡片未选中时是直角 + 底部硬线，与设计稿 .note-card{8px} 不符。改为直接构造 BoxShadow（Sm / Md / Xs 三档，保证生效）；笔记卡片统一 8px 圆角 + 6px 外边距 + 淡边框，选中淡绿、hover 淡灰并轻微抬升；卡片／浮层／侧栏项／工具按钮全部加 0.12s BrushTransition；工具条分割线由 line 换成更淡的 lineSoft。
编辑器排版偏生硬只有基础 CSS，缺少选区色、光标色、字距、滚动条、图片质感。补 caret-color:#1A9E5C、::selection:#CFE9D9、正文 letter-spacing:.005em 与 text-wrap:pretty、标题负字距、hr、引用右圆角、代码块 1px 边框、单元格 hover、图片软阴影、链接下划线偏移、9px 细滚动条、占位符淡入。
本轮只动 Tonote.App 的显示层与 App.axaml，未改任何 Core 数据模型、同步逻辑或云端 JSON 字段，三端共用数据契约不受影响。图标路径在 Icons 静态构造时自检，失败会把 glyph 写到 stderr，避免以后又悄悄回退成 emoji。
如实说明：后台验证会话里 Avalonia 窗口没有映射到交互桌面（GetWindowRect 只有 160×28），因此没能做像素级截图比对；视觉参数以设计稿令牌与代码为准，最终观感需在本机启动 GUI 确认。
